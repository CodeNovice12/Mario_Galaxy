# Super Mario Galaxy — Landing page conceito

Landing page cinematográfica de estudo para um filme fictício, com atmosfera cósmica e animações guiadas pela rolagem.

**Stack:** HTML, CSS e JavaScript puro, com GSAP + ScrollTrigger e particles.js.

## Destaques
- Hero com vídeos transparentes (WebM com alpha e fallback MP4)
- Menu de navegação animado e marquee
- Seção de personagens com fundo de partículas
- Trailers em carrossel (embeds do YouTube) e contador regressivo animado
- Layout responsivo, com protótipos no Figma documentados em `prints/` e `docs/`

## Rodar localmente
Abra `index.html` no navegador (ou use a extensão Live Server do VS Code).
